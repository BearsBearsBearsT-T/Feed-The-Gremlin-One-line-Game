# Feed-The-Gremlin-One-line-Game
A one-line html tiny, silly web game where you feed an increasingly hungry gremlin.
<img width="1227" height="600" alt="image" src="https://github.com/user-attachments/assets/1d21cdbe-f81b-49de-b26b-cfea971cd5e3" />

Every time you click the 'Feed Me" button, the 'snacks fed' counter goes up. as the counter goes up, the gremlin demands more snacks until, he just wants the whole pantry. 

I made the game using HTML in VScode and I then compressed it to one line for a fun challenge. I am not very familiar with html, but this was a fun challenge :).
